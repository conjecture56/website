# Find contributor-ready data collaborations

Use this guide to identify concrete collaboration opportunities in data
science, AI, data engineering, open data, open science, civic technology, and
community-led data projects.

## Search vocabulary

Combine relevant technical or domain terms with:

- call for contributors;
- contributors wanted;
- open collaboration opportunities;
- contributor-ready projects;
- open-source volunteer opportunities;
- open science working groups;
- data for good projects;
- civic tech volunteering;
- community-led data projects;
- `help wanted`, `good first issue`, and `contributions welcome` issues.

These phrases are discovery aids, not evidence that an opportunity is ready.

## Validation checklist

Before adding a candidate to the board, verify:

1. The repository or project has recent activity.
2. A concrete, unassigned contribution queue or active workstream exists.
3. The project provides an explicit contribution or joining path.
4. A working contact channel, meeting, forum, Slack, or Discord is available.
5. External contributors are explicitly accepted.
6. A bounded contribution can be completed in approximately two to four weeks.
7. The work can produce a visible output such as merged code, data,
   documentation, analysis, a model, or a report.
8. Assignment, CLA, license, domain, geographic, and data-governance constraints
   are understood.
9. The collaboration offers a realistic path to working with the team rather
   than submitting unsolicited work without coordination.

## Exclusions

Do not add:

- prize challenges or competitions;
- generic communities without concrete work;
- inactive repositories;
- formal jobs;
- speculative projects based only on the existence of a public API or dataset;
- assigned issues unless maintainers explicitly request additional help;
- projects without a verifiable contribution path or maintainer contact.
