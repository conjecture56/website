02 / Connect

Configure OpenCode

After a successful inspection, we generate one ready-to-use configuration containing your key and every model available to it.

  1. 1

    Run the installer

    Paste your key when prompted (input is hidden). The installer detects your OpenCode version (V1 or V2) and configuration file, adds the provider with every model available to your key, and backs up the file first. It needs python3, node, bun, or jq.

    Terminal
    curl -fsSL https://conjecture56.org/install.sh | sh

    The installer stores your API key inside the chosen OpenCode configuration file on this machine.

  2. 2

    Verify the connection

    Run one deterministic prompt to confirm the provider and model are available.

    Terminal
    A verification command will appear with your configuration.
i

A note on credentials

The generated configuration contains your API key for fast setup. Treat that file like a password: never commit it to Git, share it in support messages, or expose it in screenshots. If you believe a key has leaked, ask its issuer to rotate it.
